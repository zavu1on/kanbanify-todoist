# Общее. Руководство по разработке и оформлению кода

Конвенции и процесс, одинаковые для обоих процессов приложения. Специфика — в [`BACKEND_CODE_STYLE_GUIDE.md`](BACKEND_CODE_STYLE_GUIDE.md) и [`FRONTEND_CODE_STYLE_GUIDE.md`](FRONTEND_CODE_STYLE_GUIDE.md); правила отсюда действуют в обоих, повторно там не пересказываются.


## Язык кода

Весь код — на английском: имена, комментарии, JSDoc, сообщения ошибок, тексты в тестах, ключи и служебные строки. Тексты, которые видит пользователь, — тоже на английском (отдельного словаря локализации в проекте нет).

Русский язык — только в документации (`docs/`, `README.md`, `CLAUDE.md`). Русские подписи из [`SPECIFICATION.md`](SPECIFICATION.md) задают **смысл** элемента, а не строку для вставки в код, — переводи их при реализации.


## Форматирование и импорты

Форматирование и линт — Biome (`yarn format`, `yarn lint`), общий конфиг для всего проекта — [`biome.json`](../biome.json). Ключевое, что нельзя авто-исправить правкой руками мимо форматтера:

- Двойные кавычки, точки с запятой всегда, скобки у всех стрелочных функций (`(x) => x`, не `x => x`)
- Сортировка и группировка импортов — автоматическая (`organizeImports`), не выстраивай их руками


## SDLC

1. разработка новой фичи / внесение правок
2. добавление / актуализация unit-тестов
3. проверь, нет ли висящих ссылок, нужно ли обновить документацию (`docs/README.md`, `CLAUDE.md`) или завести новый ADR (последнее согласуй со мной); актуализируй [`DEFERRED.md`](DEFERRED.md) — удали строки, которые эта правка закрыла, и заведи строку на то, что осознанно отложено из-за отсутствующего функционала
4. `yarn typecheck` & `yarn format`
5. `yarn test`
6. ожидание ревью от человека
7. `/git-commit`

Шаги 4 и 5 частично автоматизированы хуками Claude Code (см. раздел «Хуки» в [`../CLAUDE.md`](../CLAUDE.md)). Хуки — страховка, а не замена шагам: запускай проверки и сам, не дожидаясь конца сессии.


## Claude Code

- Фича, затрагивающая оба процесса, — скилл `feature-fullstack`; он же определяет IPC-контракт до того, как начнётся код
- Ревью готового дифа на соответствие руководствам — агент `code-reviewer`
- Оформление коммита — скилл `git-commit`
