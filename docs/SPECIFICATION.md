# Техническое задание


## Авторизация

При входе в приложение необходимо авторизоваться через Todoist API, вставить 
Access Token в поле ввода, после успешной авторизации пользователь попадает в приложение.


## Сайдбар 

Слева расположен сайдбар, с помощью которого происходит навигация по вкладкам:
- + (Создание новой задачи)
- Поиск (Search),
- Дашборд (Dashboard)
- Задачи (Tasks),
- Сегодня (Today),
- Календарь (Calendar). 

Далее идет отсекающая линия - разделитель, после которого отображаются проекты.
Внизу сайдбара отображается карточка с аватаром пользователя и его никнеймом, ниже - версия приложения. При нажатии на карточку пользователя появляется модальное окно/всплывашка над карточкой пользователя с возможностью выхода.


## Добавление задачи 

При нажатии на "+" открывается модальное окно (см. Задача-детальное отображение) для создания новой задачи.

## Дашборд

Первая страница, которая встречает пользователя при открытии приложения. Весь дашборд поделен на карточки с метриками.

Общая информация по задачам. Отображает, сколько задач создано пользователем всего, сколько сколько не выполнено, сколько выполнено. Ниже отображается, сколько просроченных задач, сколько задач на сегодня, сколько задач с дедлайном. Ниже идет таблица с задачами, у которых дедлайн истекает меньше чем через 2 недели (см. Задача-элемент списка), вместо дедлайна отображается актуальное количество дней до дедлайна.

Информация по kanban доске. Отображает метрики по незавершенным задачам, сколько без статуса, сколько todo, сколько in-progress, сколько completed.

## Задачи

На данной станице отображаются все невыполненные задачи (аналогично странице Inbox в Todoist). Так как Todoist имеет встроенную пагинацию с максимальным количеством элементов списка 200, то внизу страницы должна быть кнопка "догрузить еще". 

Данная страница имеет два вида отображения: 1) списочное (аналогично странице Inbox в Todoist); 2) kanban - 4 колонки (списка задач), которые делят задачи на "без статуса", todo, in-progress и completed. Kanban статусы определяются Todoist тегами, причём тег completed не равен выполненной задаче. У каждого из kanban-столбцов должен быть "+" для создания задачи с определённым kanban статусом.

### Карточка

Задача-элемент списка отображает название задачи, дедлайн (с подсветкой в зависимости от того, просрочена/не просрочена задача), канбан-статус (если есть), лейблы (если есть), проект (если есть), количество подзадач. Также у данной карточки есть чекбокс, который завершает задачу (при нажатии на него, должна быть возможность отменить нажатие в течение 5 секунд).

Задача-детальное отображение - модальное окно, аналогичное модальному окну задачи в Todoist, но с отображением community полей (без полей, которых нет в community версии). Данное отображение также служит и для создания/редактирования карточки. Включает в себя поля: название, описание, дедлайн, канбан-статус (если есть), лейблы (если есть), проект (если есть), подзадачи.

При добавления лейблов, зарезервированных для kanban статусов, должно отображаться предупреждение.


## Сегодня 

Копия экрана "Задачи", но все карточки должны иметь дедлайн - сегодня.


## Календарь

На данной станице отображаются все невыполненные задачи, у которых выставлен дедлайн (аналогично странице Upcoming в Todoist). Так как Todoist имеет встроенную пагинацию с максимальным количеством элементов списка 200, то должен быть реализован функционал автоматической догрузки карточек.

Данная страница имеет два вида отображения: 1) списочное (аналогично странице Upcoming в Todoist). С отображением Задач-элементов списка и возможностью добавить задача с дедлайном на выбранную дату; 2) calendar - списочное отображение, представленное в виде календаря, также в с возможностью добавить задача с дедлайном на выбранную дату.
